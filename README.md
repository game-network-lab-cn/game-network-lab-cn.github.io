# 低延迟实验室

游戏卡顿、Ping 忽高忽低、人物瞬移或频繁掉线？低延迟实验室提供常见问题的排查指南和 Ping 日志分析工具，帮助你找到下一步该检查什么。

## 能做什么

- **按症状排查：** 找到 Wi-Fi 卡顿、Ping 突然升高、低 Ping 仍然卡等问题的对应指南。
- **分析 Ping 日志：** 查看延迟变化、P95、未收到回应的样本，以及两轮测试的差异。
- **保存结果：** 复制分析摘要，或者导出 CSV，方便复测时对比。
- **学习基础概念：** 了解 RTT、延迟波动和丢包分别能说明什么。

工具在浏览器中处理你输入的测试数据，不会主动上传日志。Ping 数据不能单独证明游戏服务器或宽带运营商存在故障。
